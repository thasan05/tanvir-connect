# Tanvir Connect

A minimal, responsive personal social-links page for Md. Tanvir Hasan.

## Deploy

This is a static site. Enable GitHub Pages in the repository settings and select the `main` branch with `/ (root)`, or import the repository into Vercel.

## Files

- `index.html` — page markup and styles
- `profile.jpg` — profile photograph
- `favicon.svg` — browser tab icon

Before using the page publicly, update the social profile links in `index.html` to your exact profiles.
